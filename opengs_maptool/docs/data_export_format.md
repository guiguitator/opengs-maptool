# Data Export Format

The data generated by the editor (*territory definitions*, *territory history*, *province definitions*) can be exported in various formats, such as:

- `JSON`
- `CSV`
- `YAML`
- `XML`

> The semicolon (`;`) is used to separate data in CSV files.

## Data structure

For each piece of data generated, a data structure is defined to ensure interoperability.

> For clarity, only one entry will be provided for each example. In reality, a data file may contain a large number of territories or provinces.

### Territory definitons

#### JSON

```json
{
    "TRT000001": {
        "territory_type": "land",
        "R": 121,
        "G": 131,
        "B": 193,
        "x": 1301.14,
        "y": 648.38
    }
}
```

#### CSV

```csv
id;territory_type;R;G;B;x;y
TRT000001;land;121;131;193;1301.14;648.38
```

#### YAML

```yaml
TRT000001:
  territory_type: land
  R: 121
  G: 131
  B: 193
  x: 1301.14
  y: 648.38
```

#### XML

```xml
<?xml version="1.0" ?>
<territories>
    <territory id="TRT000001">
        <territory_type>land</territory_type>
        <R>121</R>
        <G>131</G>
        <B>193</B>
        <x>1301.14</x>
        <y>648.38</y>
    </territory>
</territories>
```

### Territory history

#### JSON

```json
{
    "TRT000001": {
        "provinces": [
            "PRV000012",
            "PRV000013"
        ]
    }
}
```

#### CSV

```csv
id;provinces
TRT000001;PRV000012,PRV000013
```

#### YAML

```yaml
TRT000001:
  provinces:
  - PRV000012
  - PRV000013
```

#### XML

```xml
<?xml version="1.0" ?>
<territories>
    <territory id="TRT000001">
        <provinces>
            <province>PRV000012</province>
            <province>PRV000013</province>
        </provinces>
    </territory>
</territories>
```

### Province definitons

#### JSON

```json
{
    "PRV000001": {
        "province_type": "lake",
        "R": 37,
        "G": 131,
        "B": 175,
        "x": 1231.82,
        "y": 219.37,
        "province_terrain": "lakes"
    }
}
```

#### CSV

```csv
id;province_type;R;G;B;x;y;province_terrain
PRV000001;lake;37;131;175;1231.82;219.37;lakes
```

#### YAML

```yaml
PRV000001:
  province_type: lake
  R: 37
  G: 131
  B: 175
  x: 1231.82
  y: 219.37
  province_terrain: lakes
```

#### XML

```xml
<?xml version="1.0" ?>
<provinces>
    <province id="PRV000001">
        <province_type>lake</province_type>
        <R>37</R>
        <G>131</G>
        <B>175</B>
        <x>1231.82</x>
        <y>219.37</y>
        <province_terrain>lakes</province_terrain>
    </province>
</provinces>
```
