# Command List

Here is a list of the commands available in the editor console.

> Please keep in mind that this feature is experimental and still in its early stages. The commands currently available are primarily intended for demonstration and testing purposes.

| Command   | Arguments | Description                                                  |
|-----------|-----------|--------------------------------------------------------------|
| `clear`   | None      | Clears the console message history                           |
| `discord` | None      | Displays the link to the OpenGS Discord server               |
| `github`  | None      | Displays the link to the editor's GitHub repository          |
| `history` | None      | Displays the history of console commands entered by the user |
