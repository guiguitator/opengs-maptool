# Console

The console is a tool located in the right-hand panel. It allows you to execute various commands to retrieve information or perform actions.

Using the two buttons located below the console, you can export or import a console's history into the editor.

> This feature is currently under development, and very few of the current commands are useful. Additionally, in the future, the console will contain logs of all actions performed in the editor.

To view the list of currently available commands, please visit the [Command List](command_list.md) page.
